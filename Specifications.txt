I have reserved a domain name with Cloudflare.  It is "RompfortheRescues.org".  Use Cloudfare exclusively for hosting this project.

I would like a web site that handles an organization that puts on events to help fund a number of charities that deal with animals.
There should be a navigation row at the top of the page (after title) with links to Events, Charities, and a link to volunteer in general
rather than to a specific event.

In addition to hosting events, links to affiliated charities are on the page to encourage donations directly to the charities.

Each of the events raises funds to support one or more charities.  Each Event will have a default "registration" button and a "volunteer" 
button.  The "receipt" button collects the person(s) email and other information, then links to stripe to accept the payment. We want to
send them an email receipt (once their payment is accepted) to bring to the event.  Email subject is "receipt" and be from 
                    "donotreply@RompfortheRescues.org" 
and have a cc to RompfortheRescues@gmail.com.  
The email has event data in the body. No information is stored.  Payments will be handled by Stripe.  For now just make a demo version.

Volunteers may "register" to sign up for any event or for no specific events and for general or specific duties.  There is no fee to volunteer, but an email receipt should be sent to the volunteer from "donotreply@RompfortheRescues.org" with a cc to "rompfortherescues@gmail.com". Registration for volunteers should optionally collect event, duty preference and contact info, including telephone number (optional) on volunteer to include in the email. Information collected is not stored, but is included in the email.  We will get attendance numbers from the cc's email.

The form for general volunteering (no specific event) and the form for specific volunteering (clicking "volunteer" button on an event) will
be the same form except the information on the specific event will be missing from the general volunteering and the phone number will not
be optional on the general volunteering.

Emails will be sent using an existing Resend account.

Each of the Charities can receive donations, or donations can be made for administration.
Donations for specific charities will be accomplished by linking to their appropriate web pages for donations (see XML file <PayLink>.
Donations use the Payment Methods.

Keep the javascript, style sheets, and index.html file in separate files.  I already have an XML file named data.xml, so refer to that file in the code, the code below is a copy of that file.
Keep environment variables in a separate file for testing that will not be pushed to the origin of github.
